## Guidelines

- Only save templates the user explicitly approved or sent without edits
- Note the context — what situation triggered this template
- Date when last used — remove templates unused for 90+ days
- Templates are starting points, not rigid scripts — always adapt to context
- Cross-reference with style refinements for tone consistency
- Keep to 5-10 templates max — quality over quantity
